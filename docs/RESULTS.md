# Results guide

`results_submit/` contains derived CMNIST artifacts and `results_submit_img100/` contains legacy ImageNet100C pilot artifacts. Neither directory is a destination for new training runs.

Use only these output roots for new work:

```text
results/cmnist/e3b/
results/imagenet100c/seed<seed>/E3b_<condition>_<algorithm>/
```

CMNIST’s 11-grid analyser output is a predictive worst-environment metric. The four-anchor identification audit is a separate release-gated workflow and is not generated by the active quickstart.

Any pre-transition ImageNet100C checkpoint, any 15-corruption legacy evaluation, and all upstream QRM/SWAD results are diagnostic or control artifacts. Do not combine them with the canonical CMNIST or ImageNet100C matrices without an explicit protocol label.
