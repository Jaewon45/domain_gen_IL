# Legacy Documentation

These documents record historical plans, implementation notes, audits, and
superseded dataset directions. They are retained for provenance, not as current
run instructions.

- `EXPERIMENT_PLANS_[CMN&ImgC].md`: historical experiment design.
- `IMPLEMENTATION_PROGRESS_[CMN].md`: historical implementation log.
- `implementation_theory_audit.md`: historical theory/CVaR audit.
- `SANITY_CHECKLIST.md`: historical pre-run checklist.
- `README_IMAGENET_C_LEGACY.md`: retired non-100 ImageNet-C extension plan.

Current phase names and result interpretation are in
[docs/RESULTS.md](../RESULTS.md). The active ImageNet extension is described in
[docs/README_IMAGENET100C.md](../README_IMAGENET100C.md).
