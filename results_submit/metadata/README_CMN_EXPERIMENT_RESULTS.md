# Report Metadata

This metadata directory belongs to the CMNIST result bundle. For active provenance and regeneration guidance, see [docs/RESULTS.md](../../docs/RESULTS.md) and [REPRODUCIBILITY.md](../../REPRODUCIBILITY.md).

## CMN

The surrounding `results_submit/tables/` and `results_submit/figures/` files
contain derived CMNIST report artifacts. The `_4anchor` E3b files are the
focused support-removal analysis. They must not be combined with upstream QRM
reproduction records without preserving the protocol label.

## Img100C

ImageNet-100-C is a separate external constructed-domain result family. Its
metadata and focused evaluation outputs are not part of this CMNIST bundle; see
[docs/README_IMAGENET100C.md](../../docs/README_IMAGENET100C.md).
